# Planner art direction: "Field atlas, printed in two inks"

The owner shared a moodboard on 2026-11-15. This is what we took from it and
how it maps onto the planner. The Figma file is still the layout reference. This
file covers the look.

## The idea in one line

The planner looks like a 1970s field atlas printed in two inks: cobalt on bone
paper, with stippled grain. Data is drawn as dots, because our data *is* dots:
91,800 H3 cells.

## Hero (later)

The hero (a lone figure on a stippled plain under a cobalt sky) is parked for now. The owner asked to ship the planner screens first.

## System

| Element | Rule | From the moodboard |
|---|---|---|
| Paper | Bone `#efe8d8` with a faint grain overlay | DevDsgn "Blue Grain Editorial", hollycurates annual reports |
| Ink | Text `#121842`, muted `#4b5179`, rules at 16% ink | print, not screen grey |
| Accent | Cobalt `#1d33c9`. A selected item is inverted to bone on cobalt | Palakonweb cobalt plates |
| Verdicts | match = cobalt ■ ✓, miss = vermilion `#c23b20` ✕, unknown = ochre `#8a6410` ? (hollow). Shape and glyph always go with colour | annual-report spot colours |
| Type | Source Serif 4 for titles (tight, balanced lines); Geist Mono for labels and numbers (tabular) | s3ththompson library, emirbekin blueprints |
| Panels | "Plates" with `+` corner marks and a mono `FIG. 04 — …` caption | emirbekin interactive blueprints |
| Maps | A dithered dot globe: every land cell is one dot coloured by its funnel class | praveenisomer dither globe, s3ththompson places globe |
| Imagery | Derek's Figma Moon and Mars engravings, multiplied onto the paper | praveenisomer dither and halftone studies |
| Details | Concentric radii, tabular numbers, `text-wrap: balance`, press scale 0.97, transitions on named properties only | jakubkrehel interface cheat sheet |

## What we did not take

- Saturated multi-colour gradients (uisabor, uihssn backgrounds, Forest Carbon).
  They fight two-ink print and cut the contrast between verdicts.
- A single "match %" in a hero or card. Rule 4 still applies everywhere.
